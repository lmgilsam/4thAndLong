# Voice takes for the Film Room #001 ad (Alabama QBs)

Typecast voices (Leo's Basic plan, commercial license): Duke on play-by-play, Cameron on color.
Cut from one Typecast export (AD_3_voice.mp3, Nov 6, 2026) at its pauses, silence trimmed.
Duke's takes are sped up 1.1x (the tag 1.2x). Scene times in `src/ad/timeline-film-room.ts`
are fitted to these takes, so new takes of different lengths need the times refitted.

Run `node scripts/ad/record-ad.cjs --ad film-room --audio-only` (with `npm run dev` running) to
remix the sound onto frames you already recorded. `.wav`, `.mp3` and `.m4a` all work.
